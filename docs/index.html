claude-hook-kit

Guardrails for Claude Code, switched on per project.

Nine hooks for Claude Code. Install them once. Each one stays off in every folder until that folder opts in with one config file.

Install once, from a terminal:

git clone https://github.com/scottconverse/claude-hook-kit
cd claude-hook-kit
node install.mjs

Needs Node.js. No npm packages.

What you get

Nine hooks. Each one has one job.

inject-rules

Event: SessionStart, UserPromptSubmit

Adds your project's rules file to Claude's context. It never blocks anything.

deploy-gate

Event: PreToolUse (Bash, PowerShell)

Blocks a deploy command until a gate file for the commit passes its checks.

walk-brief-guard

Event: PreToolUse (Write, Edit, Bash, PowerShell)

Blocks a walk brief that breaks a rule you set, such as a missing required section.

read-ledger-gate

Event: PreToolUse (Write, Edit, Bash, PowerShell)

Blocks any write to a code file until a read ledger lists the upstream files that were read, with true line counts.

db-write-guard

Event: PreToolUse (Bash, PowerShell)

Blocks a command that can write to a live database, unless a fresh go file is present.

no-idle

Event: Stop

Blocks the end of a turn while background workers are left unattended.

double-check

Event: Stop

Blocks the end of a turn once, so Claude re-checks its work against a checklist.

measure-gate

Event: Stop

Blocks the end of a turn while the code is newer than the newest measurement receipt. No "done" without a number.

wake

Event: Stop (runs in the background)

After a delay, 20 minutes by default, wakes Claude with a status list of its workers.

How it works

  1. Install once. Run node install.mjs. It adds the hooks to your Claude Code settings and backs up the settings file first.
  2. Opt in per project. Add .claude/hook-kit.json to the project folder. List only the hooks you want, with their settings.
  3. Hooks run only there. A hook looks for that file in its own folder, then in each folder above it. The nearest file wins. No file means no effect.

Example config

This is the double-check section from examples/minimal.hook-kit.json. Put it in .claude/hook-kit.json to turn that hook on in one project.

{
  "double-check": {
    "quote": "Owner: \"Check everything twice, read everything, do not skim, check the code.\"",
    "label": "my project"
  }
}

Safe by default

  • Off until opted in. A hook does nothing in a folder with no config file, or with no section for that hook.
  • The installer backs up your settings file before it changes it.
  • It never duplicates entries. Running the installer again replaces the kit's own entries.
  • Uninstall removes only the kit's entries. Your other hooks stay.
  • No npm dependencies. The kit uses Node.js and its built-in modules.
